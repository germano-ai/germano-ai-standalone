Collegati al Germano Server

Germano Client usa i Chatbot e Agenti AI e il motore di un Germano Server della tua rete locale. Scrivi il suo indirizzo (oppure lascialo vuoto per la ricerca automatica).

Accedi

Su questo Germano Server la gestione utenti è attiva: accedi con l'utente e la password impostati dall'amministratore.

In rete locale il collegamento non è cifrato (HTTP): usa Germano solo su reti fidate.

Sanitizzazione manuale

Trascina dei file o incolla un testo: il Germano Server oscura i dati personali e ti restituisce la versione protetta, da usare con qualsiasi AI. Le corrispondenze restano solo su questo dispositivo e servono a rimettere i tuoi dati nelle risposte.

⬆ Trascina qui i file da anonimizzare PDF, Word, Excel, PowerPoint, immagini, email, testo… Il file anonimizzato mantiene il suo formato.

Le CLI e gli SDK di questo computer possono passare da Germano: imposta questi indirizzi come Base URL del servizio. Germano anonimizza le richieste e ripristina i dati nelle risposte.
